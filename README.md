# App Trainer

Aplicativo web para montar treinos, controlar séries, repetições, carga e tempo de descanso.

## Funcionalidades

- Criar treinos personalizados
- Adicionar exercícios, séries, repetições, carga e descanso
- Executar treino com timer automático
- Registrar histórico de treinos
- Exportar dados em JSON
- Importar dados de um arquivo JSON
- Funciona no celular e no computador
- Os dados ficam salvos no navegador

## Como usar

1. Abra `index.html` no navegador.
2. Vá em **Treinos** e crie um treino.
3. Adicione os exercícios.
4. Vá em **Treinar**, escolha o treino e inicie.
5. Use **Série concluída** para avançar e iniciar o descanso.
6. Em **Dados**, exporte ou importe seu backup.

## Publicar no GitHub Pages

1. Entre em **Settings** do repositório.
2. Abra **Pages**.
3. Em **Source**, escolha `Deploy from a branch`.
4. Selecione `main` e a pasta `/root`.
5. Salve.

O site ficará disponível em:

`https://robininhub.github.io/App-Trainer/`
